A Brigada de Garçons

"Threading Concorrente"

O servidor principal fica na porta recebendo os clientes (accept). Para cada cliente novo, ele chama um garçom exclusivo (threading.Thread) para cuidar daquela mesa.

📢

O Megafone da Sala

"Broadcast vs Unicast"

Broadcast: o servidor itera pela lista de sockets e repassa a mensagem para todos, exceto o remetente. Unicast: envia apenas para o socket do usuário desejado.

📐

O Protocolo de Aplicação

"A Gramática da Mensagem"

O TCP entrega bytes crus. Seu projeto precisa definir os comandos: ENTRAR <nome>, MSG <texto>, CHUTE <letra> e SAIR.

💀

A Desconexão Graciosa

"Zero Bytes no recv()"

Quando um cliente fecha o programa, o recv() retorna b'' ou gera exceção. O servidor deve remover o socket da lista para não enviar bytes para um canal morto.

Código Base Multithreaded em Python

🐍 1. servidor.py (Multithreaded com Tratamento de Queda) 

import socket
import threading

HOST = '0.0.0.0'
PORT = 9999

clientes = []
lock = threading.Lock()

def broadcast(mensagem, conexao_remetente=None):
    with lock:
        for cliente in list(clientes):
            if cliente != conexao_remetente:
                try:
                    cliente.send(mensagem.encode('utf-8'))
                except:
                    clientes.remove(cliente)
                    cliente.close()

def tratar_cliente(conexao, endereco):
    print(f"[CONEXÃO] Novo cliente conectado: {endereco}")
    with lock:
        clientes.append(conexao)
    
    conexao.send("BEM-VINDO ao Servidor! Digite suas mensagens:\n".encode('utf-8'))
    broadcast(f"[SISTEMA] O cliente {endereco[0]} entrou no chat.\n", conexao)

    while True:
        try:
            dados = conexao.recv(1024)
            if not dados:
                break
            mensagem = dados.decode('utf-8').strip()
            print(f"[{endereco[0]}]: {mensagem}")
            broadcast(f"[{endereco[0]}]: {mensagem}\n", conexao)
        except ConnectionResetError:
            break

    print(f"[DESCONEXÃO] Cliente {endereco} desconectou.")
    with lock:
        if conexao in clientes:
            clientes.remove(conexao)
    conexao.close()
    broadcast(f"[SISTEMA] O cliente {endereco[0]} saiu do chat.\n")

servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
servidor.bind((HOST, PORT))
servidor.listen()
print(f"[ESCUTANDO] Servidor multiusuário ouvindo na porta {PORT}...")

while True:
    conn, addr = servidor.accept()
    thread = threading.Thread(target=tratar_cliente, args=(conn, addr), daemon=True)
    thread.start()

💻 2. cliente.py (Com Thread Receptora em Segundo Plano)

O cliente utiliza uma Thread exclusiva para escutar o servidor sem bloquear o input() do usuário: 

import socket
import threading
import sys

SERVER_IP = '127.0.0.1'  # Ou o IP do servidor na rede local
SERVER_PORT = 9999

cliente = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
try:
    cliente.connect((SERVER_IP, SERVER_PORT))
except Exception as e:
    print(f"Erro ao conectar: {e}")
    sys.exit()

def receber_mensagens():
    while True:
        try:
            msg = cliente.recv(1024).decode('utf-8')
            if not msg:
                print("\n[DESCONECTADO] Conexão encerrada pelo servidor.")
                cliente.close()
                break
            print(msg, end='')
        except:
            break

# Inicia thread para escuta contínua
thread_escuta = threading.Thread(target=receber_mensagens, daemon=True)
thread_escuta.start()

print("Conectado! Digite sua mensagem e aperte Enter (ou 'sair'):")
while True:
    try:
        texto = input()
        if texto.lower() == 'sair':
            cliente.close()
            break
        cliente.send(texto.encode('utf-8'))
    except KeyboardInterrupt:
        cliente.close()
        break

4 Ideias de Projetos para Implementar

🎯 1. Jogo da Forca / Adivinhação Colaborativa

O servidor sorteia uma palavra secreta. Múltiplos jogadores conectados enviam palpites de letras. O servidor atualiza o boneco e a palavra oculta (_ _ A _ _) para todos os clientes a cada rodada.

Comandos: CHUTAR <letra> | PLACAR | NOVOJOGO
🔨 2. Leilão Eletrônico em Tempo Real

O servidor abre itens com preço inicial e um timer regressivo (ex: 30s). Clientes dão lances. O maior lance atualiza a tela de todos e reseta o cronômetro até o martelo bater: "Dou-lhe uma, dou-lhe duas, VENDIDO!".

Comandos: LANCE <valor> | STATUS | MEUSITENS
🧠 3. Quiz Competitivo (Show do Milhão)

O servidor envia uma pergunta com 4 alternativas e dá 15 segundos para responder. Quem responder primeiro ganha pontos. O servidor mantém e transmite o placar geral ao final de cada rodada.

Comandos: RESPOSTA <A|B|C|D> | RANKING
⚔️ 4. Batalha Naval ou RPG Textual

Partidas 1v1 ou coop onde o servidor valida as coordenadas (FOGO B4), calcula danos, informa "Água" ou "Acertou Navio" e sincroniza o tabuleiro entre os combatentes.

Comandos: ATACAR <X,Y> | MAPA | CHAT <msg>

Armadilhas Comuns de Concorrência & Sockets

⚠️ 1. Travar no input()

Se o cliente não tiver uma thread separada para recv(), ele fica bloqueado no input() do teclado e nunca exibe as mensagens recebidas de outros usuários até que o usuário aperte Enter.

Solução: Criar a thread de escuta com daemon=True no cliente!
⚠️ 2. Modificar Lista Enquanto Itera

Fazer clientes.remove(c) dentro de um for c in clientes dispara o erro RuntimeError: list changed size during iteration.

Solução: Itere sobre uma cópia da lista: 'for c in list(clientes):'.
⚠️ 3. Esquecer SO_REUSEADDR

Ao reiniciar o servidor rapidamente, o erro OSError: [Errno 98] Address already in use pode ocorrer devido ao estado TIME_WAIT do TCP.

Solução: Adicione 'setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)' antes do bind.
