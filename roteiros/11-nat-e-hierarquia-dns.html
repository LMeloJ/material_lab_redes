Como a Internet Funciona: NAT Overload e a Hierarquia DNS Global

O IPv4 tem apenas ~4,3 bilhões de endereços, o que seria insuficiente para os bilhões de dispositivos mundiais. A solução salvadora foi o NAT/PAT (Port Address Translation): milhares de hosts privados (192.168.1.x) navegam na Internet pública através de um único endereço IP público. Em paralelo, a resolução de nomes mundiais ocorre através de uma árvore distribuída que conecta Servidores Raiz (.), TLDs (.com) e Servidores Autoritativos.

PAT Rule: ip nat inside source list 1 int s0/0/0 overload
Serial WAN: HWIC-2T (clock rate 64000)
DNS Root: Root (.) → TLD (.com) → Auth

Modelos Mentais: O Porteiro PAT e a Árvore DNS

🏢

O Porteiro do Edifício

"PAT (Port Address Translation)"

Todos os moradores mandam cartas para fora usando o endereço do condomínio (IP Público). O porteiro anota a caixa postal (Porta TCP) para saber a qual apartamento entregar quando a resposta chegar.

🌳

A Pirâmide da Agenda Global

"Delegação Hierárquica DNS"

Nenhum servidor do mundo guarda todos os domínios. O Root (.) aponta para os servidores `.com`, que apontam para a autoridade `labredes.com`, que finalmente entrega o IP exato.

🏷️

Inside Local vs Inside Global

"RG Privado vs Passaporte Público"

Inside Local é seu IP privado (`192.168.1.10`). Inside Global é a fantasia pública que o roteador veste no seu pacote para ele viajar pela Internet (`200.100.50.2:1025`).

⏱️

O Relógio do Link Serial

"clock rate (DCE vs DTE)"

Em enlaces de telecomunicação seriais V.35, o lado da operadora (DCE) gera a pulsação de clock que sincroniza a transmissão dos bits de longa distância.

Guia de Configuração Cisco IOS

⚙️ 1. Roteador de Borda Edge-R1: NAT Overload & Interfaces 

enable
configure terminal
hostname Edge-R1

! 1. Interface LAN Privada
interface gigabitEthernet 0/0
 ip address 192.168.1.1 255.255.255.0
 ip nat inside
 no shutdown
exit

! 2. Interface WAN Serial Pública
interface serial 0/0/0
 ip address 200.100.50.2 255.255.255.252
 ip nat outside
 no shutdown
exit

! 3. Rota Padrão (Default Gateway para o Provedor)
ip route 0.0.0.0 0.0.0.0 200.100.50.1

! 4. ACL identificando a rede privada a ser traduzida
access-list 1 permit 192.168.1.0 0.0.0.255

! 5. Ativação do NAT Overload (PAT)
ip nat inside source list 1 interface serial 0/0/0 overload

do write memory

Armadilhas Comuns de NAT & WAN

⚠️ 1. Esquecer da Palavra "overload"

Digitar ip nat inside source list 1 interface serial 0/0/0 sem a palavra overload no final cria um NAT dinâmico 1:1. O primeiro PC que navegar rouba o único IP público e ninguém mais consegue acessar a Internet!

Sempre inclua 'overload' no comando de NAT!
⚠️ 2. Inverter "inside" e "outside"

Colocar ip nat outside na interface Gigabit (LAN) e inside na Serial (WAN) faz com que o roteador não aplique as regras de tradução e descarte o pacote silenciosamente.

LAN = ip nat inside | WAN = ip nat outside.
⚠️ 3. Esquecer o "clock rate" no cabo Serial

Em cabos seriais, a ponta DCE precisa do comando clock rate 64000 na interface para que a linha suba para o estado Up / Up.

Comando na ponta DCE: clock rate 64000.
