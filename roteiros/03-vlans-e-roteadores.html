Segmentação Lógica com VLANs e o Truque do "Router-on-a-Stick"

Uma rede sem segmentação (flat network) sofre com tempestades de broadcast e vulnerabilidades de espionagem. As VLANs (Virtual Local Area Networks) particionam um switch físico em múltiplos switches virtuais isolados. Para que eles conversem de volta, usamos uma única interface de roteador dividida em sub-interfaces com marcação IEEE 802.1Q.

Padrão Trunk: IEEE 802.1Q (dot1q)
VLANs do Lab: VLAN 10 (Vendas) & VLAN 20 (Engenharia)
Comando Chave: encapsulation dot1Q <id>
1

Modelos Mentais: Como Funcionam as VLANs e o Tronco

🧱

A Parede de Concreto L2

"Isolamento Físico Virtual"

Dois PCs plugados lado a lado no mesmo switch físico, se estiverem em VLANs diferentes, é como se estivessem em prédios diferentes: nem o broadcast de ARP passa.

🏷️

O Carimbo de Passaporte

"Tag 802.1Q de 4 Bytes"

Ao sair por uma porta Trunk, o frame Ethernet ganha 4 bytes extras com o ID da VLAN (12 bits). Na porta Access de entrega final, essa tag é removida.

🍭

O "Router-on-a-Stick"

"O Pirulito de Rede"

Em vez de passar 20 cabos físicos para 20 VLANs, passa-se 1 único cabo físico operando como Trunk. O roteador cria interfaces virtuais (ex: g0/0.10 e g0/0.20).

🛡️

Fronteira de Segurança

"Controle Centralizado"

Como todo tráfego entre departamentos precisa obrigatoriamente subir até o Roteador, é no Roteador que você depois aplica listas de controle de acesso (ACLs) e firewalls.

Guia de Configuração Cisco IOS

⚙️ 1. Configuração do Switch 2960 (VLANs & Trunk)

Crie as duas VLANs, associe as portas de acesso dos computadores e defina a porta Gig0/1 conectada ao roteador como Trunk: 

enable
configure terminal

! 1. Criação das VLANs de Vendas e Engenharia
vlan 10
 name VENDAS
exit

vlan 20
 name ENGENHARIA
exit

! 2. Portas de Acesso (Access Ports para os PCs)
interface fastEthernet 0/1
 switchport mode access
 switchport access vlan 10
exit

interface fastEthernet 0/2
 switchport mode access
 switchport access vlan 20
exit

! 3. Porta Tronco para o Roteador (Trunk 802.1Q)
interface gigabitEthernet 0/1
 switchport mode trunk
 switchport trunk native vlan 1
exit

! 4. Validação
do show vlan brief
do show interfaces trunk

🧭 2. Configuração do Roteador 2911 (Router-on-a-Stick)

Ative a interface física pai com no shutdown (não atribua IP a ela!) e crie as sub-interfaces lógicas para cada VLAN com o comando encapsulation dot1Q <id>: 

enable
configure terminal

! 1. Ativando a interface física principal (Sem IP!)
interface gigabitEthernet 0/0
 no shutdown
exit

! 2. Sub-interface lógica para a VLAN 10 (Vendas)
interface gigabitEthernet 0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.254 255.255.255.0
exit

! 3. Sub-interface lógica para a VLAN 20 (Engenharia)
interface gigabitEthernet 0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.254 255.255.255.0
exit

! 4. Validação de Rotas e Status
do show ip interface brief
do show ip route

Armadilhas Comuns em VLANs & Roteamento Inter-VLAN

⚠️ 1. Inverter a Ordem no Roteador

Tentar digitar o comando ip address ... na sub-interface antes do encapsulation dot1Q gera erro de sintaxe imediato no Cisco IOS: "Configuring IP on a LAN subinterface requires 802.1Q".

Regra: Sempre digite primeiro 'encapsulation dot1Q <id>' e só depois o IP!
⚠️ 2. Esquecer de Ativar a Interface Pai

Mesmo configurando as sub-interfaces .10 e .20 corretamente, se você não executar no shutdown na interface física g0/0, o link permanecerá vermelho e inoperante.

Sintoma: Triângulos vermelhos no cabo entre Switch e Roteador.
⚠️ 3. Gateway Incompatível no Host

Configurar o PC da VLAN 10 com IP 192.168.10.1 e colocar o gateway como 192.168.20.254 faz com que o PC recuse a rota padrão ou descarte o pacote por conflito de sub-rede.

O Default Gateway deve pertencer estritamente à mesma sub-rede do nó!
