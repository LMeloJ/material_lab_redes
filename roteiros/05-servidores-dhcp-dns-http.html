A Tríade Fundamental da Internet: DHCP, DNS & HTTP

Quando você liga seu computador e abre uma página da web, uma orquestração de três protocolos invisíveis acontece em segundos: o DHCP aluga um endereço IP; o DNS traduz o nome legível em um IP de servidor; e o HTTP transporta a página web pela porta 80.

DHCP: Portas UDP 67/68 (DORA)
DNS: Porta UDP 53 (A Record)
HTTP: Porta TCP 80 (200 OK)
1

Modelos Mentais: Os Três Pilares da Navegação

📜

O Cartório de Imigração (DHCP)

"Ciclo DORA"

Você chega na cidade sem nome (IP 0.0.0.0) e grita: "Quem pode me dar um endereço?". O servidor responde com um IP, máscara, gateway e DNS.

📖

A Lista Telefônica (DNS)

"Human-Readable to Binary"

Seres humanos lembram de nomes ("site.com"), mas roteadores só sabem rotear números binários ("10.0.1.100"). O DNS faz essa ponte instantânea.

🍽️

O Garçom Web (HTTP)

"Request & Response"

O cliente entrega uma comanda: GET /index.html HTTP/1.1. O servidor cozinha o HTML e entrega na mesa com o status HTTP/1.1 200 OK.

🔄

O Despachante L3 (Helper)

"ip helper-address"

Roteadores bloqueiam broadcasts por padrão. O comando ip helper-address pega o grito DHCP dos clientes e transforma em unicast para o servidor.

Guia de Configuração no Packet Tracer

🧭 1. Roteador Cisco: IP Helper-Address (DHCP Relay)

Como os clientes estão na sub-rede 192.168.1.0/24 e o servidor DHCP está na sub-rede de servidores 10.0.1.0/24, você deve habilitar o retransmissor DHCP na interface GigabitEthernet 0/0 do roteador: 

enable
configure terminal

! Interface dos Clientes
interface gigabitEthernet 0/0
 ip address 192.168.1.254 255.255.255.0
 ip helper-address 10.0.1.10
 no shutdown
exit

! Interface dos Servidores
interface gigabitEthernet 0/1
 ip address 10.0.1.254 255.255.255.0
 no shutdown
exit

Armadilhas Comuns em Servidores de Infraestrutura

⚠️ 1. Esquecer de Ligar o Serviço (Botão "On")

No Packet Tracer, ao configurar DHCP ou DNS em um Server-PT, o serviço vem desligado (Off) por padrão. Se você não clicar em On, os pacotes serão descartados.

Sintoma: O PC recebe endereço APIPA 169.254.x.x.
⚠️ 2. Esquecer o "ip helper-address"

O DHCP Discover é emitido em broadcast. Como o servidor está em outra sub-rede, o roteador descarta a solicitação silenciosamente a menos que o helper esteja configurado na interface dos clientes.

Solução: 'ip helper-address 10.0.1.10' na porta Gi0/0.
⚠️ 3. Apontar o DNS para o Próprio Cliente

No pool do DHCP, alguns alunos colocam o Default Gateway como Servidor DNS. A menos que o roteador tenha cache DNS ativo, o navegador não resolverá site.com.

O campo DNS Server no pool deve ser exatamente 10.0.1.20!
