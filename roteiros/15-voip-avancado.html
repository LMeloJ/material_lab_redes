Modelos Mentais: Telefonia IP Corporativa & Dial-Peers

📞

O que é um Dial-Peer?

É a tabela de roteamento para voz. Associa padrões de dígitos discados (ex: 2...) a um endereço IP de destino remoto (o roteador PBX da filial).

🔔

Sinalização (SIP/SCCP)

Mensagens de controle trocadas antes e depois da chamada (INVITE, RINGING, OK, BYE). Informam quem está ligando e ajustam os parâmetros do canal de voz.

🎙️

Mídia em Tempo Real (RTP)

Após atender, a voz é digitalizada em amostras de 20ms e transmitida diretamente via Real-time Transport Protocol (UDP) com baixíssima latência.

⚡

QoS & DSCP Expedited (EF)

Em redes corporativas, os pacotes RTP recebem etiqueta DSCP EF (46) para furar a fila de tráfego de downloads e e-mails no link WAN, evitando engasgos no áudio.

Configuração de Dial-Peers nos Roteadores Cisco IOS

1. Configuração do Dial-Peer na Matriz (R-VOIP-MATRIZ)

Configuramos o dial-peer para rotear qualquer discagem iniciada com 2 e 4 dígitos para o IP WAN da Filial: 

enable
configure terminal
hostname R-VOIP-MATRIZ

! Configuração da interface WAN inter-filiais
interface GigabitEthernet0/0
 ip address 10.255.0.1 255.255.255.252
 no shutdown
exit

! Configuração do Dial-Peer VoIP para a Filial
dial-peer voice 2000 voip
 description ROTEAMENTO-CHAMADAS-PARA-FILIAL
 destination-pattern 2...
 session target ipv4:10.255.0.2
 codec g711ulaw
 no vad
exit

! Verificação dos dial-peers cadastrados
do show dial-peer voice summary

2. Configuração do Dial-Peer na Filial (R-VOIP-FILIAL)

Na Filial, fazemos a rota simétrica para que qualquer discagem iniciando em 1 e 4 dígitos seja entregue na Matriz: 

enable
configure terminal
hostname R-VOIP-FILIAL

! Configuração da interface WAN inter-filiais
interface GigabitEthernet0/0
 ip address 10.255.0.2 255.255.255.252
 no shutdown
exit

! Configuração do Dial-Peer VoIP para a Matriz
dial-peer voice 1000 voip
 description ROTEAMENTO-CHAMADAS-PARA-MATRIZ
 destination-pattern 1...
 session target ipv4:10.255.0.1
 codec g711ulaw
 no vad
exit

Armadilhas Comuns em Telefonia IP Multi-Site

❌ Quantidade de Pontos

destination-pattern incorreto

Cada ponto . representa exatamente um dígito. Se seus ramais têm 4 dígitos (ex: 2001), o padrão precisa ser 2... (1 dígito fixo + 3 curingas). Se colocar 2.., o telefone não reconhecerá a discagem.

⚠️ Roteamento IP Ausente

Target IP inalcançável

O dial-peer apenas instrui a camada de aplicação de voz. Se o roteamento IP de camada 3 (como rotas estáticas ou OSPF) entre 10.255.0.1 e 10.255.0.2 não estiver respondendo a ping, a chamada falhará com tom de ocupado.

🎙️ Incompatibilidade de Codec

g711ulaw vs g729r8

Ambos os dial-peers devem negociar o mesmo algoritmo de compressão de áudio. Se um lado estiver em G.711 e o outro em G.729 sem hardware de transcoding DSP, a chamada cairá imediatamente após atender.
