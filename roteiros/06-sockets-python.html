A Analogia Mental: O Telefone Corporativo

Se você memorizar este modelo mental, nunca mais vai esquecer qual função deve chamar ou por que ela trava a execução:

☎️

socket.socket()

"Comprar o aparelho telefônico"

Você comprou o hardware e o cabo, mas o telefone ainda não está plugado em tomada nenhuma. Ele apenas sabe falar IPv4 e TCP.

📍

bind(IP, Porta)

"Ligar o telefone no ramal 9999"

O prédio é o IP da máquina. A porta 9999 é o ramal exclusivo. O bind fixa seu aparelho naquele ramal específico.

👂

listen(fila)

"Ligar a campainha do ramal"

Seu telefone agora está apto a receber chamadas do mundo exterior. O número entre parênteses é quantas chamadas podem esperar na fila.

📞

accept()

"Esperar tocar e atender!"

Bloqueante: o programa pausa aqui até tocar. Quando atende, ele cria uma linha privada (conexao) e deixa a linha mãe livre para novos clientes!

Etapa 1: A Conexão Básica (Aperto de Mão)

Vamos criar dois arquivos separados. O objetivo desta etapa é apenas ver a conexão ocorrer com sucesso e depois encerrar.

servidor_basico.py 
import socket

# 1. Cria socket IPv4 (AF_INET) e TCP (SOCK_STREAM)
servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Evita o erro "Address already in use" se você reiniciar rápido!
servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

# 2. Vincula à porta 9999 de qualquer interface da máquina
servidor.bind(('0.0.0.0', 9999))

# 3. Coloca em modo de escuta (fila de até 1 pendente)
servidor.listen(1)
print("--- SERVIDOR AGUARDANDO CONEXÃO NA PORTA 9999 ---")

# 4. accept() é BLOQUEANTE: o código congela aqui até um cliente chegar
conexao, endereco = servidor.accept()
print(f"🎉 Conexão estabelecida com sucesso! IP de origem: {endereco}")

# 5. Encerra a conexão criada com o cliente
conexao.close()
servidor.close()
Atenção: O método accept() retorna uma tupla de 2 itens: o novo socket exclusivo e os dados de IP/porta de quem ligou.
cliente_basico.py 
import socket

# 1. Cria socket com as mesmas regras da chamada
cliente = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. Conecta ativamente ao IP do Servidor
# '127.0.0.1' (localhost) aponta para a sua própria máquina
print("Tentando conectar ao servidor na porta 9999...")
cliente.connect(('127.0.0.1', 9999))

print("🚀 Conectado com sucesso!")

# 3. Fecha o socket
cliente.close()

Etapa 2: A Conversa (Troca de Dados)

Uma vez conectado, o canal TCP se comporta como dois canos contínuos. O que um lado escreve no send(), o outro lado lê no recv().

servidor_dados.py 
import socket

servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
servidor.bind(('0.0.0.0', 9999))
servidor.listen(1)
print("Aguardando mensagem...")

conexao, endereco = servidor.accept()

# recv(1024): lê até 1024 bytes do buffer TCP (também é bloqueante!)
dados_brutos = conexao.recv(1024)
msg_recebida = dados_brutos.decode('utf-8')

print(f"[{endereco[0]}] disse: {msg_recebida}")

# Responde de volta para o cliente
resposta = f"Eco do Servidor: recebi '{msg_recebida}' com sucesso!"
conexao.send(resposta.encode('utf-8'))

conexao.close()
servidor.close()
cliente_dados.py 
import socket

cliente = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
cliente.connect(('127.0.0.1', 9999))

# 1. Envia mensagem formatada em bytes
msg = "Olá, Servidor! Consegue me ouvir?"
cliente.send(msg.encode('utf-8'))

# 2. Aguarda a resposta vinda do servidor
resposta_bytes = cliente.recv(1024)
resposta_texto = resposta_bytes.decode('utf-8')

print(f"Servidor respondeu: {resposta_texto}")

cliente.close()

Etapa 3: Servidor Persistente & Protocolo de Aplicação

Um servidor real não encerra após atender um único cliente. Ele roda em um loop contínuo while True: aceitando requisições sequenciais e processando comandos.

servidor_monitor.py 
import socket
import platform
import datetime

# Função de negócio: processa o protocolo
def processar_comando(cmd):
    if cmd == "SISTEMA":
        return platform.system() + " " + platform.release()
    elif cmd == "NOME":
        return platform.node()
    elif cmd == "HORA":
        return datetime.datetime.now().strftime("%H:%M:%S")
    else:
        return "ERRO: Comando desconhecido. Use: SISTEMA, NOME ou HORA"

servidor = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
servidor.bind(('0.0.0.0', 9999))
servidor.listen(5)
print("🚀 Servidor de Monitoramento online na porta 9999!")

while True:
    conn, addr = servidor.accept()
    print(f"\n[+] Conexão recebida de: {addr}")
    
    cmd_cliente = conn.recv(1024).decode('utf-8').strip().upper()
    print(f"    Comando solicitado: {cmd_cliente}")
    
    resposta = processar_comando(cmd_cliente)
    conn.send(resposta.encode('utf-8'))
    
    # Fecha a conexão individual, mantendo o servidor vivo
    conn.close()
cliente_interativo.py 
import socket

def menu():
    print("\n" + "="*30)
    print("   PAINEL DE MONITORAMENTO")
    print("="*30)
    print("Opções: SISTEMA | NOME | HORA | SAIR")
    return input(">> Digite o comando: ").strip().upper()

while True:
    cmd = menu()
    if cmd == "SAIR":
        print("Encerrando cliente...")
        break
    
    # Cria uma nova conexão para cada requisição (estilo HTTP/1.0)
    c = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    c.connect(('127.0.0.1', 9999))
    c.send(cmd.encode('utf-8'))
    
    resultado = c.recv(1024).decode('utf-8')
    print(f"\n[RESPOSTA RECEBIDA]: {resultado}")
    c.close()

Armadilhas Clássicas & Como Debugar

Erros que 95% dos estudantes encontram no primeiro dia de sockets:

Address already in use

Ocorre quando você fecha o servidor com Ctrl+C e tenta rodar de novo logo em seguida. A porta ainda está no estado TCP TIME_WAIT pelo SO.

Solução: Adicione antes do bind:
servidor.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
ConnectionRefusedError

O cliente tentou conectar em uma porta onde não existe nenhum processo executando o listen().

Solução: Certifique-se de que o servidor já está rodando no outro terminal antes de disparar o cliente.
TypeError: bytes-like object

Ocorre ao chamar send("texto") direto, esquecendo de codificar a string para o formato binário.

Solução: Sempre use
.encode('utf-8') no envio e
.decode('utf-8') na recepção.
