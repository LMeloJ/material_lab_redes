Modelos Mentais: Segurança Corporativa com ACLs e Telefonia

🛡️

ACL Estendida (L3 + L4)

Diferente das ACLs padrão (que filtram apenas IP de origem), a ACL estendida inspeciona IP de origem, IP de destino, protocolo (TCP/UDP/ICMP) e porta de aplicação (ex: 80, 443, 22).

📍

Aplicação Inbound na Fonte

A regra de ouro de segurança da Cisco é: aplique ACLs estendidas o mais próximo possível da origem do tráfego (in na interface SVI Vlan 40) para não desperdiçar ciclos da CPU do Core.

🚫

O Implicit Deny All

Toda lista de controle de acesso termina com uma regra invisível que bloqueia tudo o que não foi explicitamente permitido. Lembre-se sempre de liberar o tráfego legítimo!

📶

Isolamento de Visitantes (GUEST)

Visitantes conectados ao Wi-Fi devem navegar livremente na Internet (HTTP/HTTPS e DNS), mas serem sumariamente bloqueados se tentarem alcançar servidores internos ou SSH de switches.

Guia de Comandos Cisco IOS: ACLs, Wi-Fi e Telefonia CME

1. Criação da ACL Estendida 101 no SW-CORE-MDF

No Switch Core 3560, aplicamos a política de segurança que isola a rede de visitantes e protege a DMZ: 

enable
configure terminal

! 1. Permitir DHCP (Portas 67 e 68 UDP) e DNS (Porta 53 UDP) para os visitantes
access-list 101 permit udp 192.168.40.0 0.0.0.255 any eq bootps
access-list 101 permit udp 192.168.40.0 0.0.0.255 any eq domain

! 2. Bloquear sumariamente qualquer tentativa de acesso dos visitantes à DMZ
access-list 101 deny ip 192.168.40.0 0.0.0.255 192.168.30.0 0.0.0.255 log

! 3. Bloquear qualquer acesso dos visitantes à VLAN de Gerência (MGMT 99)
access-list 101 deny ip 192.168.40.0 0.0.0.255 192.168.99.0 0.0.0.255 log

! 4. Bloquear acesso dos visitantes aos computadores administrativos (VLAN 10)
access-list 101 deny ip 192.168.40.0 0.0.0.255 192.168.10.0 0.0.0.255 log

! 5. Permitir acesso à Internet geral (HTTP/HTTPS)
access-list 101 permit tcp 192.168.40.0 0.0.0.255 any eq 80
access-list 101 permit tcp 192.168.40.0 0.0.0.255 any eq 443

! 6. Aplicação Inbound na SVI da VLAN 40
interface Vlan40
 ip access-group 101 in
exit

! Verificação das regras e contadores de match
show access-lists 101

2. Configuração do Servidor Telefônico CME no R-VOIP (Cisco 2811)

No roteador de telefonia, ativamos o CallManager Express para registrar os telefones IP 7960 dos andares: 

enable

hostname R-VOIP

! Ativação do serviço de telefonia

Armadilhas Finais de Segurança & ACLs

❌ Bloquear DHCP e DNS

Esquecer de liberar UDP 67 e 53

Se a sua ACL 101 não tiver permissão explícita para DHCP (UDP 67/68) e DNS (UDP 53), os visitantes conectarão ao Wi-Fi mas nunca receberão IP ou não conseguirão resolver nenhum domínio da Internet.

⚠️ Inversão da Ordem das Regras

Permit All antes de Deny

As ACLs operam em avaliação top-down. Se você colocar permit ip any any no início da ACL, as regras de bloqueio subsequentes para a DMZ jamais serão executadas.

📞 Telefones sem IP da Opção 150

TFTP Option 150 ausente no DHCP

Os telefones IP Cisco 7960 precisam da opção option 150 ip 192.168.20.1 configurada no pool DHCP para saberem em qual endereço buscar os arquivos de configuração XML e registrar o ramal.
