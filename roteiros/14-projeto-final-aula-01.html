Modelos Mentais: Arquitetura Corporativa de 2 Andares

🏢

MDF (Main Distribution Facility)

Localizado no 1º pavimento. É o coração do edifício corporativo: abriga o Switch Core L3, os servidores da DMZ, conexões de telecom e a chegada do link de Internet.

🪜

IDF (Intermediate Distribution)

Localizado no 2º pavimento. Atende as estações de trabalho e telefones IP do andar, concentrando o cabeamento horizontal antes de subir para o backbone vertical.

🛡️

DMZ (Zona Desmilitarizada)

VLAN 30 exclusiva para os 4 servidores (Web, DNS, Arquivos e DHCP). Isola ativos críticos para que usuários nas VLANs de visitantes ou ADM não acessem portas não autorizadas.

🏷️

Tronco Vertical 802.1Q

O enlace Gigabit entre o Switch de Acesso do 2º andar e o Core no 1º andar transporta todas as VLANs simultaneamente etiquetadas com tags de 4 bytes 802.1Q.

Guia de Comandos Cisco IOS: Passo a Passo

1. Configuração do Switch Core L3 no MDF (Cisco 3560/3650)

No switch core, criamos o banco de VLANs e configuramos o tronco com encapsulamento explícito dot1q: 

enable
configure terminal
hostname SW-CORE-MDF

! 1. Criação do Banco de VLANs
vlan 10
 name ADM
vlan 20
 name VOIP
vlan 30
 name DMZ
vlan 40
 name GUEST
vlan 99
 name MGMT
exit

! 2. Configuração do Tronco Vertical para o IDF (2º Andar)
interface GigabitEthernet0/1
 description UPLINK-TRUNK-PARA-IDF-2F
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40,99
 no shutdown
exit

! 3. Configuração das Portas de Servidores da DMZ (VLAN 30)
interface range FastEthernet0/1 - 4
 description SERVIDORES-DMZ-DATACENTER
 switchport mode access
 switchport access vlan 30
 spanning-tree portfast
 no shutdown
exit

2. Configuração do Switch de Acesso do 2º Andar (SW-ACC-2F 2960)

No switch de acesso do IDF, provisionamos as portas dos usuários com as VLANs de dados e voz (Voice VLAN): 

enable
configure terminal
hostname SW-ACC-2F

! Criação das VLANs no switch de acesso
vlan 10
 name ADM
vlan 20
 name VOIP
vlan 40
 name GUEST
vlan 99
 name MGMT
exit

! Configuração do Tronco para o Core
interface GigabitEthernet0/1
 description TRUNK-PARA-SW-CORE-MDF
 switchport mode trunk
 switchport trunk allowed vlan 10,20,30,40,99
 no shutdown
exit

! Configuração das portas de trabalho (PC + Telefone IP em cascata)
interface range FastEthernet0/1 - 8
 description ESTACOES-ADM-E-VOIP
 switchport mode access
 switchport access vlan 10
 switchport voice vlan 20
 spanning-tree portfast
 no shutdown
exit

! Porta do Access Point de Visitantes
interface FastEthernet0/10
 description AP-WIFI-GUEST
 switchport mode access
 switchport access vlan 40
 no shutdown
exit

Armadilhas Comuns no Projeto Integrador

❌ Erro no Switch L3

Esquecer o comando encapsulation

No Cisco Catalyst 3560/3650, tentar digitar switchport mode trunk sem antes rodar switchport trunk encapsulation dot1q resulta em erro de sintaxe imediato porque o hardware suporta ISL legado.

⚠️ Servidores na VLAN 1

Esquecer de associar à VLAN 30

Conectar os 4 servidores do Data Center no Core e esquecer de aplicar switchport access vlan 30 deixará os servidores na VLAN nativa 1 padrão, quebrando a comunicação na hora do roteamento L3.

💾 Perda pós-reinício

Não salvar o running-config

Lembre-se sempre de executar copy running-config startup-config (ou simplesmente write) antes de fechar o Packet Tracer para evitar perda de configuração.
