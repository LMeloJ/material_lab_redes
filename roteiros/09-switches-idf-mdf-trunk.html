Estrutura Hierárquica: Closets MDF, IDF e Tronco Gigabit

Em qualquer instalação corporativa ou campus universitário, os cabos não vão diretamente de cada computador até a sala de servidores. A norma TIA/EIA-568 limita cabos de par trançado a 100 metros. Para contornar isso, usamos IDFs (Intermediate Distribution Facilities) em cada andar conectados por uma linha tronco ao MDF (Main Distribution Facility).

Norma Física: TIA/EIA-568 (Máx 100m)
Backbone Vertical: Gigabit Trunk 802.1Q
Ambiente: Packet Tracer Physical View

Modelos Mentais: MDF vs IDF no Mundo Real

🏢

O Saguão Central (MDF)

"Data Center Principal"

Onde chegam os links de operadoras externas (Internet), residem os roteadores de borda, switches centrais (Core) e os servidores de missão crítica.

🚪

O Ponto de Apoio (IDF)

"Rack do Andar"

Um rack menor localizado em cada andar. Ele atende os usuários locais e manda tudo para o MDF por um único cabo de backbone de alta velocidade.

📏

A Barreira dos 100 Metros

"Limite Elétrico do Cobre"

Passar cabos do 10º andar até o subsolo excederia 100m, degradando os pacotes. O switch IDF funciona como regenerador de sinal dentro do limite normativo.

🔌

O Patch Panel

"A Tomada de Proteção"

Em vez de plugar o cabo da parede direto no switch, fixa-se no Patch Panel. Assim, alterações de mesa não quebram as portas caras do switch ativo.

Guia de Configuração Cisco IOS

🔀 1. Configuração dos Switches SW-IDF e SW-MDF

// SW-IDF (Andar dos Usuários)
enable
configure terminal
hostname SW-IDF

vlan 10
 name OPERACIONAL
vlan 20
 name SERVIDORES
exit

! Porta do Backbone Vertical (Trunk)
interface gigabitEthernet 0/1
 switchport mode trunk
 description TRUNK-PARA-MDF
exit

! Portas das Bancadas de Trabalho
interface range fastEthernet 0/1-10
 switchport mode access
 switchport access vlan 10
exit
// SW-MDF (Data Center Central)
enable
configure terminal
hostname SW-MDF

vlan 10
 name OPERACIONAL
vlan 20
 name SERVIDORES
exit

! Recebe o Backbone do IDF
interface gigabitEthernet 0/1
 switchport mode trunk
 description TRUNK-DO-IDF
exit

! Tronco conectado ao Roteador R-MDF
interface gigabitEthernet 0/2
 switchport mode trunk
 description TRUNK-ROUTER-ON-A-STICK
exit

! Porta de Acesso do Servidor Intranet
interface fastEthernet 0/1
 switchport mode access
 switchport access vlan 20
exit

🧭 2. Configuração do Roteador Central R-MDF 

enable
configure terminal
hostname R-MDF

interface GigabitEthernet0/0/0
 no shutdown
exit

! Gateway e Encapsulamento VLAN 10 (IDF)
interface GigabitEthernet0/0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
exit

! Gateway e Encapsulamento VLAN 20 (MDF)
interface GigabitEthernet0/0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
exit

! Pool DHCP para os computadores do IDF
ip dhcp pool POOL-IDF-USUARIOS
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
exit

Armadilhas Comuns em IDF, MDF e Trunks

⚠️ 1. Trunk em Apenas um Lado

Se você configurar switchport mode trunk no SW-IDF e esquecer do SW-MDF, o link não fechará o protocolo 802.1Q corretamente e o tráfego inter-closets será descartado.

Sempre valide com 'show interfaces trunk' nos DOIS switches!
⚠️ 2. Esquecer de Criar as VLANs

Mesmo que uma porta seja Trunk, o switch só transporta frames de VLANs que existem no seu banco de dados local. Você precisa criar vlan 10 e vlan 20 em ambos os equipamentos.

Execute 'show vlan brief' para conferir a base de dados.
⚠️ 3. Ultrapassar os 100 Metros

No modo Físico do Packet Tracer, cabos de par trançado com mais de 100m apresentam perda grave de pacotes e alta taxa de colisão/timeout.

Utilize fibra óptica para backbones inter-prédios longos.
