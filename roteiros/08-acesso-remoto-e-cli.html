Laboratório 08 • Gerenciamento Seguro de Ativos

Administração Remota com SSHv2 e Endurecimento da CLI

Nenhum engenheiro de redes vai até o data center toda vez que precisa alterar uma rota. O acesso remoto via SSH (Secure Shell) sobre a porta 22 TCP permite gerenciar switches e roteadores com criptografia de ponta a ponta. Neste lab, você configurará chaves assimétricas RSA no Cisco ISR 4331, fechará portas inseguras (Telnet) e provisionará o DHCP direto na CLI.

Protocolo Seguro: SSHv2 (Porta 22 TCP)
Chaves Criptográficas: RSA 1024/2048 bits
Linhas VTY: transport input ssh

Modelos Mentais: Telnet vs SSH e Linhas VTY

📨

O Cartão Postal (Telnet)

"Texto Claro / Plaintext"

Qualquer um que espione o cabo com Wireshark lê o usuário e a senha como se estivessem escritos num cartão postal aberto.

🔐

A Caixa Blindada (SSH)

"Túnel Criptografado RSA/AES"

Mesmo que o atacante capture todos os pacotes, ele só enxergará caracteres aleatórios indecifráveis sem a chave privada do roteador.

🎛️

As Linhas Virtuais VTY

"line vty 0 4"

O roteador não tem 5 portas seriais físicas extras. As VTYs são portas virtuais que aceitam conexões de terminal simultâneas através da rede IP.

🛡️

Gerência Out-of-Band

"Isolamento Administrativo"

A máquina do administrador (PC-Admin) fica em uma sub-rede isolada (10.0.0.0/24), sem contato direto com o tráfego dos computadores comuns.

Guia de Configuração no Cisco IOS

⚙️ 1. Script Completo de Endurecimento SSH & Interfaces 

enable
configure terminal
hostname R-LAB

! 1. Domínio necessário para gerar a chave RSA
ip domain-name labredes.local

! 2. Usuário de privilégio máximo com senha protegida
username admin privilege 15 secret cisco123

! 3. Geração da chave criptográfica assimétrica RSA
crypto key generate rsa
1024

! 4. Ativação da versão 2 do SSH
ip ssh version 2

! 5. Configuração restrita das linhas VTY (bloqueia Telnet)
line vty 0 4
 transport input ssh
 login local
 exit

! 6. Senha privilegiada de enable
enable secret cisco123

! 7. Interfaces de Rede (Clientes e Gerência)
interface GigabitEthernet0/0/0
 ip address 192.168.1.1 255.255.255.0
 no shutdown
exit

interface GigabitEthernet0/0/1
 ip address 10.0.0.1 255.255.255.0
 no shutdown
exit

! 8. Pool DHCP para as estações clientes
ip dhcp excluded-address 192.168.1.1 192.168.1.10
ip dhcp pool REDE-CLIENTES
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8
exit

do write memory

Armadilhas Comuns no SSH Cisco IOS

⚠️ 1. Esquecer do "ip domain-name"

Se você tentar executar crypto key generate rsa sem antes ter definido um hostname diferente do padrão e um ip domain-name, o roteador recusará: "% Please define a domain-name first".

Sempre defina hostname e ip domain-name antes das chaves!
⚠️ 2. Esquecer do "login local"

Se nas linhas VTY você esquecer de digitar login local, o roteador não consultará a tabela de usuários locais e rejeitará o login do admin.

Comando essencial: 'login local' sob 'line vty 0 4'.
⚠️ 3. Sintaxe do Cliente SSH no Prompt

No Packet Tracer, o comando correto é ssh -l <usuario> <ip> (com traço L minúsculo). Digitar ssh admin@ip pode não ser interpretado dependendo da versão do simulador.

Use: ssh -l admin 10.0.0.1
